# Benjy The Treehopper

This is a game I developed using the Unity engine for my Software Engineering Internship at 
[Idori LLC](https://idori.com/?srsltid=AU7gw4XopFLQxBVim0v0dzGmIomT8UwMqFnsU0kfO3qb0Hkd5ilLB-ul).

It is meant to teach children about environmental sustainability through play. The game centers around a creature
whose home is about to be destroyed by deforestation, and so they must collect seeds to plant a new home.

Here is the [full game](https://play.unity.com/en/games/b1ee31bb-81ad-4bc6-b5bc-e37fb592a46e/treehopping-with-benjy), hosted on Unity Play.
